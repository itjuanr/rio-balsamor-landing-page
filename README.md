## 📖 Sobre o Projeto

O **Rio Balsamor** é um projeto de uma marca fictícia de restaurante e bar carioca, focado em alta gastronomia e coquetelaria autoral.

Este projeto foi desenvolvido através de uma **colaboração multidisciplinar** entre Design e Desenvolvimento. O objetivo foi simular um ambiente real de agência/startup, abrangendo todo o ciclo de vida do produto:

1.  **Criação da Marca:** Desenvolvimento da identidade visual e conceito da "empresa" do zero.
2.  **Briefing & Stakeholders:** Reuniões de alinhamento entre designers e partes interessadas para definir requisitos.
3.  **Desenvolvimento:** Implementação fiel do layout proposto em uma Landing Page responsiva e interativa.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias modernas e bibliotecas robustas para garantir performance e interatividade:

* ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white) **HTML5 Semântico**
* ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white) **CSS3** (Estilização personalizada e animações)
* ![Bootstrap](https://img.shields.io/badge/Bootstrap-563D7C?style=for-the-badge&logo=bootstrap&logoColor=white) **Bootstrap 5** (Grid system e componentes responsivos)
* ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black) **JavaScript & jQuery**
* **Slick Carousel:** Para sliders de coquetéis interativos e responsivos.

## 🎨 Funcionalidades

* **Design Responsivo:** Adaptável para mobile, tablet e desktop.
* **Menu Hambúrguer:** Navegação otimizada para dispositivos móveis com animação suave.
* **Hero Carousel:** Apresentação visual impactante na entrada do site.
* **Flip Cards Interativos:** Seção de coquetéis onde os cards giram ao passar o mouse (hover), revelando os ingredientes e a história da bebida.
* **Formulário de Feedback:** Seção de contato visualmente integrada ao rodapé.

## 🔧 Como Executar

Como este é um projeto estático, não requer instalação de dependências complexas.

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/seu-usuario/rio-balsamor.git](https://github.com/seu-usuario/rio-balsamor.git)
    ```
2.  **Acesse a pasta:**
    ```bash
    cd rio-balsamor
    ```
3.  **Abra o arquivo:**
    Basta abrir o arquivo `index.html` em seu navegador preferido.
    *Dica: Para uma melhor experiência, utilize a extensão "Live Server" do VSCode.*
